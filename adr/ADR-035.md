# ADR-035: Agentic 编排引擎 — deepagents 0.7.5 harness（v0.7.0 实测定稿，修订原 LangGraph 手写方案）

> **状态**: ✅ 已接受
> **日期**: 2026-08-03（原方案拍板）；2026-08-10（用户拍板升级 deepagents 0.7.5，Spike 0 全项验证）；2026-08-12（落盘）
> **风险等级**: 🟡 中（引入新依赖 harness，硬依赖打包体积 +14%）
> **依据**: Agent 化升级路径 v1.1 §4 Spike 0 + 用户拍板（2026-08-10）+ docs/deepagents-evaluation-2026-08-10.md（Spike 0 结论）+ F26 spec v1.1 §5（deepagents 集成层）+ 0.7.0 实测（PR #236）
> **原编号**: ADR-E（design/agent-upgrade-path-2026-08-03.md §5 架构决策点；v1.1 原案为「延续 LangGraph」，2026-08-10 修订为 deepagents）

## 背景

升级路径 v1.1 原案为「延续 LangGraph（现状 + 学习目标一致）」——用 LangGraph StateGraph 手写 ReAct 循环。Spike 0 验证后（2026-08-10）发现：**不同 Agent 挂不同 skill 是产品核心需求，deepagents harness 将其作为一等公民**；LangGraph 手写需自研 SKILLS_BY_ROLE 等效机制。用户拍板：agentic 写作编排升级为 **Deep Agents harness（deepagents 0.7.5）**。0.7.0 实现实测确认（PR #236 deepagents 集成 + 5 只读工具；PR #241 F27 ReAct 闭环）。

## 决策

- **编排引擎**：agentic 写作编排 = **deepagents 0.7.5 harness**（LangChain 1.x + LangGraph 底座之上的多 Agent 编排层）。
- **范围边界**：仅 **agentic 路径**使用 deepagents；F4 既有 deterministic 管线维持 LangGraph 不变（双模式，见 ADR-031）。
- **集成方式**：F26 spec §5 deepagents 集成层——静态注册表 + 工具工厂；Agent 挂 skill 走 harness 一等公民能力。
- **技术栈**：LangChain 1.x + LangGraph + deepagents 0.7.5；客户端 = langchain_openai.ChatOpenAI + custom base_url（多 Provider 兼容）。
- **Spike 证据**：docs/deepagents-evaluation-2026-08-10.md（Spike 0 全项验证记录）。

## 备选方案

| 选项 | 优点 | 缺点 | 结论 |
|------|------|------|------|
| **deepagents 0.7.5 harness（选定）** | 多 Agent + skill 一等公民；ReAct/ToolNode 内建；与 LangChain 1.x 同生态 | 新依赖（打包体积 +14%：exe 173.0MB vs 0.6.0） | ✅ 用户拍板（2026-08-10，Spike 0 全项验证） |
| LangGraph 手写循环（v1.1 原案） | 零新依赖；学习价值（手写 ReAct/ToolNode/guardrail） | 不同 Agent 挂 skill 需自研 SKILLS_BY_ROLE 等效机制；重复 deepagents 内建能力 | ❌ 修订否决（Spike 0 后拍板） |
| 其他编排框架（如 crewAI） | 生态成熟 | 与 LangChain 1.x 集成成本；团队无积累 | ❌ 否决 |
