# ADR-046: CLI 架构基线 — Typer 结构 + 恒经 HTTP + F7 输出契约 + 独立产物

> **状态**: ✅ 已接受（2026-09-01；由 ADR 域归类重构补号——CLI 层决策既往散落多文件，此 ADR 独立成篇，引用不重复）
> **日期**: 2026-09-01
> **风险等级**: 🟢 低
> **来源**: 从 ADR-030（恒经 HTTP）、F7（信封/退出码）、F33（CLI 独立产物）、F38（恒 HTTP 改造）、`cli/app.py`、`cli/commands/` 提炼
> **依据**: ADR-030（内核服务化 D1=A）、ADR-021（内核交付契约）、ADR-019（版本里程碑）

## 背景

InkFlow 的 CLI 层决策此前**散落四处**：入网传输方式在 ADR-030（恒经 HTTP）；输出信封/退出码/错误码在 F7；打包产物在 F33；恒 HTTP 改造细节在 F38。缺一份 **CLI 层自身的架构基线**作为唯一入口（本重构治理缺口）。

## 决策

1. **CLI = Typer**：`inkflow.cli.app:app`（console script `inkflow = inkflow.cli.app:app`）；命令按业务域分文件（`cli/commands/project.py / chapter.py / character.py / world.py / outline.py / timeline.py / foreshadowing.py / extract.py / audit.py / style.py / vector.py / agent_cmd.py / session.py / write.py / serve.py / kernel.py / config_cmd.py / llm.py`）。
2. **恒经 HTTP（ADR-030 ② D1=A）**：业务命令 `ensure_kernel()` → `InkFlowHTTPClient(handle)` → `127.0.0.1:{port}/api/v1/...`；**不直连 domain**。import 面收敛是本质（`python -c "import inkflow.cli.commands.project"` 不得触发 `domain.services`/`infrastructure.llm`/`infrastructure.database` 导入）——这保证 ~214ms 热调用（vs 直连 ~4.4s 冷启动）。
3. **F7 输出契约**：`--json` 全局选项；人类模式打印、JSON 模式输出 `{ok, data}` 信封；退出码 `0` 成功 / `1` 业务错误 / `2` 用法错误 / `130` Ctrl+C；错误码 `NOT_FOUND / VALIDATION_ERROR / CONFIG_ERROR / LLM_ERROR / DB_ERROR(历史) / CONTEXT_BUDGET_EXCEEDED(历史)` + 恒 HTTP 后新增 `INTERNAL_ERROR / KERNEL_ERROR`。
4. **豁免 4 组命令**（恒 HTTP 改造例外，源码事实）：`serve`（内核启动者自指）、`kernel status`（纯查询绝不拉起）、`config show/set`（操作本地 config.json，API 无对应端点）、`llm list/set-key`（操作本地 keys/，lo无状态读取端点）；`agent tools list`（本地静态枚举）。其余 14 个业务命令走 HTTP。
5. **错误映射**（HTTP 状态 → F7 码，确定性）：`404→NOT_FOUND` · `422→VALIDATION_ERROR` · `401→CONFIG_ERROR` · `500+X-InkFlow-Error-Code:LLM_ERROR→LLM_ERROR` · `500 无头→INTERNAL_ERROR` · `连接失败/超时/拉起失败→KERNEL_ERROR`。
6. **CLI 独立产物（ADR-030 ⑤ / F33）**：PyInstaller onedir 产出独立 `inkflow-cli-<ver>.zip`（含 serve 能力，纯 CLI 用户可自行拉起内核）；与 GUI 安装包并行发布；NSIS 安装器可选「添加 CLI 到 PATH」；版本与 GUI 对齐（ADR-019 SemVer）。

## 备选方案

| 方案 | 优点 | 缺点 | 结论 |
|------|------|------|------|
| **恒经 HTTP（选定）** | 单路径无漂移；CLI/MCP/GUI 共享内核 | 依赖内核可用（ensure_kernel 自动拉起） | ✅ |
| CLI 直连 domain | 少一层 | 双路径漂移；~4.4s 冷启动 | ❌ 否决 |
| 全量 import 服务层 | 无新抽象 | 违反正交性 + 性能低下 | ❌ 否决 |

## 影响

- **更易**：CLI 决策集中；内核 API 是单一真相（GUI 薄壳共享同内核，CLI 测通=核心通）；性能显著提升（import 面收敛）。
- **注意**：`cli/` 下新增本 ADR 后，`cli/` 域不再为空；4 组豁免命令是恒 HTTP 的字面例外（非领域数据、无漂移风险，登记 ADR-030）。
