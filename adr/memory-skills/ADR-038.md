# ADR-038: 记忆开关 — memory_learning 项目级配置默认 false（显式开启，F13 同构）

> **状态**: ✅ 已接受
> **日期**: 2026-08-03（拍板）；2026-08-12（落盘）
> **风险等级**: 🟢 低（默认关闭，零行为变化）
> **依据**: Agent 化升级路径 v1.1 §4 Stage 2（开关：`memory_learning: bool` 项目级配置，默认 false）+ 「AI 自动化默认关闭、显式开启」原则（F13 timeline_auto_extract 先例）
> **原编号**: ADR-H（design/agent-upgrade-path-2026-08-03.md §5 架构决策点）

## 背景

记忆系统影响生成行为（注入学习到的偏好），属「AI 自动化」范畴——按项目既有原则**默认关闭、显式开启**。开启前用户零行为变化；开启后用户可查看/删除已学偏好保持控制。

## 决策

- **开关**：`memory_learning: bool` **项目级配置，默认 false**（F13 同构：extra 键 + 请求/CLI 覆盖）。
- **默认语义**：未开启时**零行为变化**——不捕获事件、不提取偏好、不注入上下文。
- **注入面**：开启后偏好经 F6 context_provider 作为写作上下文注入（protected 层），与既有角色/世界观/伏笔注入并列。
- **可控性**：开启状态下仍可 `inkflow memory list/remove`（查看/删除已学偏好），删除后立即停止注入。
- **验收判据**：默认关闭（未开启时零行为变化）+ 删除偏好后立即停止注入。

## 备选方案

| 选项 | 优点 | 缺点 | 结论 |
|------|------|------|------|
| **项目级 extra 键默认 false（选定）** | F13 同构、显式开启原则一致；项目级语义正确 | 每项目独立开关 | ✅ 用户拍板 |
| 全局设置键（F32 白名单扩展） | 全局统一 | 偏好是**项目级**语义（不同项目不同偏好），非全局用户设置 | ❌ 否决（F28 spec §5.5 决策表） |
| 默认 true | 记忆即刻生效 | 违背「AI 自动化默认关闭、显式开启」原则；未开启用户行为变化 | ❌ 否决 |

## 影响

- ✅ 未开启零行为变化（F28 验收判据）
- ✅ 用户控制链完整：开关 → 查看 → 删除 → 立即停止注入
- ✅ 与 F13 timeline_auto_extract / ADR-031 双模式开关语义统一（extra 键 + 覆盖优先级）
- ❗ 开启后生成行为会随偏好学习漂移——透明提示（「AI 已记住…」）是配套要求
- ❗ 项目级语义意味着 GUI 需在项目设置面暴露开关（CLI 已具备）
