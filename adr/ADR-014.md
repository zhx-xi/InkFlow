# ADR-014: Prompt 模板管理 — LangChain ChatPromptTemplate

> **状态**: ✅ 已接受 · 风险等级：🟢 低 · Phase 1 实现
> **日期**: 2026-07-31
> **来源**: design/architecture-analysis-2026-07-30.md §三 ADR-014
> **依据**: ADR-015（LangChain 全家桶）

## 背景

项目有多个 Agent 角色（Architect / Writer / Auditor / Reviser）和后续用户自定义角色，每个角色有独立的 Prompt 模板。需要统一的模板加载、变量注入、验证机制。

## 决策

使用 LangChain `ChatPromptTemplate` 管理模板，通过 `PromptTemplateProtocol` 隔离领域层：

```
domain/ports/prompt_template.py              ← PromptTemplateProtocol
infrastructure/prompt/langchain_prompt_manager.py  ← LangChainPromptManager
prompts/*.yaml                                ← 模板文件
```

模板格式（YAML）：`name` / `description` / `system_prompt` / `human_prompt` / `variables` 五段式，变量缺失时提前报错。

## 备选方案

| 方案 | 优点 | 缺点 |
|------|------|------|
| ChatPromptTemplate（选定） | 类型安全、MessagesPlaceholder 动态插入 | YAML 缩进/转义需注意 |
| 手写 `str.format()` | 零依赖 | 无验证、无类型安全、消息结构难表达 |
| 自建模板引擎 | 完全可控 | 重复造轮子 |

## 影响

- ✅ 模板与代码分离，非技术人员可编辑 YAML
- ✅ 变量验证，缺少变量时提前报错
- ✅ 支持多语言 Prompt（中文/英文模板共存）
- ❗ YAML 模板编辑需注意缩进和转义
