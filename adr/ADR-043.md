# ADR-043: 打包产物 Debug 模式（统一开关 + 日志落点 + GUI DevTools + serve 可直达）

## 状态

✅ 已接受（2026-08-27；决策点 D1-D4 已由用户按建议确认）

## 背景

打包产物（便携 ZIP / NSIS 安装版）下载后**不好测试**，三层痛点均已源码核实：

1. **日志丢失 / 不可查**：`core/log.py` `resolve_log_dir()` 用 `Path(__file__).resolve().parents[3] / "logs"` 定位 backend 根。PyInstaller frozen 下 `__file__` 指向包内路径（`.../_internal/inkflow/core/log.pyc`），`parents[3]` 不再落到可写 backend 根——NSIS 装到 `C:\Program Files\InkFlow\`（只读）文件 sink 写失败；包内临时解压目录（`_MEIxxxx`）进程退出即销毁。日志实际丢失。
2. **GUI 黑盒**：`main.ts` `setupAppMenu(isPackaged)` 仅在 `isPackaged=false`（dev）注册 F12 / Ctrl+Shift+I 开 DevTools；打包版直接 `return`，无任何方式打开 DevTools；dev 诊断钩子（`__kernelInfo/__trayInfo/__trayActions`）也仅 dev 暴露。
3. **后端不可直达**：`serve.py` 用 `--port 0` 动态端口 + 每次随机 token（`secrets.token_urlsafe(32)`），uvicorn `log_level="info"`——用户不知道端口/token，无 `/docs` 入口，无法直接驱动 API 调试。

## 决策

引入**统一 Debug 模式开关** `INKFLOW_DEBUG`（1 表示开启），一个开关贯穿三层（Electron 壳 + Python 内核 + serve）。触发源优先级：**进程 env `INKFLOW_DEBUG` > instance.env `INKFLOW_DEBUG` > config.json `debug`**（与现有 `INKFLOW_DATA_DIR` 的 instance.env 语义对齐）。

开启后：

1. **后端日志**：`log_level=DEBUG`（console + 文件均 DEBUG）；文件落盘到 `config.data_dir / "logs"`（默认 `%APPDATA%/InkFlow/logs/`），不再写 bundle / 安装目录 / 临时解压目录。
2. **GUI 壳**：注册 DevTools 快捷键（F12 / Ctrl+Shift+I）并自动打开；暴露 dev 诊断钩子。打包版（`isPackaged=true`）在 debug 模式下同样生效，非 debug 行为不变。
3. **serve 可直达**：debug 时 token 用可预测值（env `INKFLOW_DEBUG_TOKEN`，缺省固定字符串），自动打开 `/docs`；uvicorn `log_level=debug`。端口仍动态，经端口文件 / 日志可查。**非 debug 保持随机 token / 不自动 /docs / info 级别**。

## 备选方案

| 选项 | 优点 | 缺点 | 结论 |
|------|------|------|------|
| A 仅 dev 构建启用 | 零改动 | 打包产物（真正痛点）反而无 debug | 否决——痛点恰在打包产物 |
| B 每层独立开关 | 各自独立 | 碎片化；三层需分别设置，学习/排查成本高 | 否决——违背「一个开关贯穿」意图 |
| C 仅 CLI `--debug` 参数 | serve 侧清晰 | 不含 Electron 壳（GUI 无 DevTools）；且 GUI 拉起内核无法传 CLI arg | 否决——无法覆盖 GUI 层 |
| **D 统一 env 开关穿透三层（选定）** | env 被 GUI 拉起的子内核继承，自动贯穿壳 + 内核；instance.env 提供「配置文件」触发；一个开关，成本低 | debug 有安全权衡（固定 token / 自动 DevTools / verbose），须标注勿生产开启 | ✅ 采纳 |

## 影响

- **更易**：打包产物测试（日志可查、GUI 可开 DevTools、后端可驱动）；排查打包版问题不再靠猜。
- **更易**：跨层一致（一个开关贯穿）；instance.env / config.json 提供免设 env 的配置文件触发。
- **注意**：debug 模式仅在 `INKFLOW_DEBUG` 开启时生效，安全影响（固定 token、自动 DevTools、verbose log）须文档标注「勿在生产开启」；非 debug 行为零变化。
- **新增/修改**：`config.py` 加 `debug: bool = False`；`log.py` frozen 分支日志目录解析；`serve.py` debug 分支；`main.ts` `isDebugMode()` 门控；`adr/README.md` 索引。
- **测试**：`tests/unit/test_log.py` 扩展 frozen 分支 + debug 级别；`main.menu.test.ts` 新增 debug 门控用例；serve 契约 `INKFLOW_READY` 交付格式不变。
