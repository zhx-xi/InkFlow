# ADR-045: API 层架构基线 — FastAPI 装配 + REST/SSE 传输 + 本地鉴权 + 错误契约

> **状态**: ✅ 已接受（2026-09-01；由 ADR 域归类重构补号——API 层决策既往散落多文件，此 ADR 独立成篇，引用不重复）
> **日期**: 2026-09-01
> **风险等级**: 🟢 低
> **来源**: 从 ADR-021（内核 REST+SSE+token）、ADR-011（异步）、F7（信封）、F23（SSE 帧）、`api/app.py`、`api/middleware/token_auth.py` 提炼
> **依据**: ADR-011（异步无阻塞）、ADR-021（本地内核进程化）、ADR-030（内核服务化）、ADR-024（云拓扑预留）

## 背景

InkFlow 的 API 层决策此前**散落四处**：传输方式（REST+SSE）与 token 鉴权在 ADR-021；内核服务化的 HTTP 暴露面在 ADR-030；SSE 帧协议在 F23；响应/错误语义在 F7 与各 spec。缺一份**API 层自身的架构基线**作为唯一入口（这正是本重构要补的治理缺口）。

## 决策

1. **应用装配**：FastAPI 应用工厂于 `api/app.py`；路由按业务域组织（project/chapter/characters/world_settings/outline/timeline/foreshadowings/extract/style/audit/vector/writing/agent/session/settings/mcp 等 30+ router），统一前缀 `/api/v1`；lifespan 内建表/迁移（`create_tables()`）；全局依赖注入（`get_provider_config_service`、`get_agentic_writer_service` 等经 deps 注入）。
2. **传输 = REST + SSE**：普通请求走 JSON REST；流式走 SSE（F23 帧协议：`delta`×N → `done`×1（携带 format_valid/word_count/model/usage）；流中错误以 `done.error` 或 `error` 帧表达）。全链路异步无阻塞（ADR-011）。
3. **本地鉴权**：`TokenAuthMiddleware` 校验 `X-InkFlow-Token`（ADR-021 本地 token 契约）；CORS 白名单仅本地源（`127.0.0.1:5173/8765`、`file://` Electron 生产，ADR-021）。
4. **响应契约**：API 端点返回**裸数据**（如 `POST /projects` → 项目对象 JSON），**不包 CLI 信封**——信封 `{ok, data}` 是 CLI/MCP 表现层职责（F7）；MCP 亦无信封。API 与表现层契约解耦。
5. **错误契约**：以 `HTTPException(status_code, detail=<中文文本>)` 表达；**仅 writing router**（LLM 管线最高频）的 500 LLM 分支加 `X-InkFlow-Error-Code: LLM_ERROR` 响应头；其余 500 兜底由 CLI 映射 `INTERNAL_ERROR`。状态码（404/422/401）由消费方确定性映射（见 ADR-046 错误映射表）。
6. **API 层零领域逻辑**：router 只做参数校验 + 依赖注入 + 调 service；不直接 import 重型基础设施（LLMClient/仓储经 deps 注入），保证接口层薄。

## 备选方案

| 方案 | 优点 | 缺点 | 结论 |
|------|------|------|------|
| **FastAPI + 域 router(选定)** | 依赖注入/校验/文档完备；30+ 域模块化 | router 文件多，需管理 import 顺序 | ✅ |
| CLI 直连 domain（不经 API） | 少一层抽象 | 双路径漂移；违背 ADR-030 恒 HTTP | ❌ 否决 |
| 全量路由加错误码响应头 | CLI/未来 MCP 错误语义精确 | 影响 17 router + 数百 API 断言 | ❌ 否决（仅 writing 扩展） |

## 影响

- **更易**：API 层决策集中，后续 F18 云端（JWT + BYOK + user/admin 双前缀，ADR-024）在本 ADR 上演进；API 契约与表现层解耦。
- **注意**：`api/` 下新增本 ADR 后，`api/` 域不再为空；各 spec 的 `参考 ADR` 可指向本 ADR 作为 API 层入口。
