# ADR-008: 配置管理 — Pydantic Settings 分层配置

> **状态**: ✅ 已接受（v2.0 扩展 LLM/RAG 配置项）
> **日期**: 2026-07-30（v2.0 更新：2026-07-31）
> **来源**: design/architecture-analysis-2026-07-30.md §三 ADR-008
> **实现**: `backend/src/inkflow/core/config.py`

## 背景

项目需要跨环境配置（本地/云端），且 LLM Provider、RAG、LangSmith 等外部服务配置项快速增长。

## 决策

使用 `pydantic-settings` 分层配置管理（环境变量 > .env 文件 > 默认值），配置按域分组。

**v2.0 新增配置分组**：
- **LangSmith**: API Key、项目名、启用开关
- **Embedding**: 模型名（`BAAI/bge-small-zh-v1.5`）、推理设备
- **向量库**: chromadb 持久化路径、collection 列表
- **LLM 超时/重试**: 请求超时、最大重试次数

## 备选方案

| 方案 | 优点 | 缺点 |
|------|------|------|
| pydantic-settings（选定） | 类型安全、自动校验、与 Pydantic 生态一致 | 需维护配置模型 |
| 裸环境变量 + os.environ | 零依赖 | 无校验、无类型、无默认值管理 |
| yaml 配置文件 | 可读性好 | 需自建加载/校验 |

## 影响

- ✅ 配置类型安全，错误配置在启动时即失败
- ✅ 新增配置项只需扩展 Pydantic 模型
- ❗ 配置项增多后需注意分组维护
