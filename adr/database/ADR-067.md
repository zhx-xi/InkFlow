# ADR-067: 时间线正式表零未定事件 + 后置时间归一 + 未定入暂存（待确认区）

- **状态**: ✅ 已接受
- **日期**: 2026-10-11
- **风险等级**: 🟡 中（新增**写路径准入不变量** —— 提取管线不再把未定事件写入 `timeline_events`；改变世界序**数据面**的可见集合）
- **来源**: [#1581](https://github.com/zhx-xi/InkFlow/issues/1581)（0.17.0 · rc3 反馈修复批 W11a 轨 1；用户拍板 2026-10-11：A1-a / A2 / A3）
- **关联**: 承接 [#1526](https://github.com/zhx-xi/InkFlow/issues/1526)（提取补 `time_display`，判据未达成）；形态承接 [#1541](https://github.com/zhx-xi/InkFlow/issues/1541) / [#1564](https://github.com/zhx-xi/InkFlow/issues/1564) / [#1565](https://github.com/zhx-xi/InkFlow/issues/1565)；两段式暂存同构 [#1545](https://github.com/zhx-xi/InkFlow/issues/1545) / [#1548](https://github.com/zhx-xi/InkFlow/issues/1548) / [#1551](https://github.com/zhx-xi/InkFlow/issues/1551)；**不改** [ADR-065](ADR-065.md)（多纪元三列）与 §2.7 S1-S10（时序语义）

## 背景

### 现象（rc3 隔离库实测）

时间线「世界序」**完全退化为未知列表**：头部 `未知 222`（= 事件总数）、分页 `共 0 刻度`、主区仅 ~2/222 条可见。

| 字段 | 值 |
|---|---|
| 事件总数 | 222 |
| `time_value` 非空 | **0（0%）** |
| `time_display` 非空 | 157（70.7%） |
| `era` 非空 | 0（全默认轴） |

### 三层根因（源码实证）

| 层 | 位置 | 机理 |
|---|---|---|
| ① 定位判据只认数值 | `frontend/.../components/timeline-band.ts` `bandGlobal()` | 只读 `time_value`（或 `era_value`/`era_scale`）→ 全 null ⇒ 刻度 0 ⇒ 全部进 `unknown` |
| ② #1526 的「原文兜底」**不可达** | `.../timeline-axis-labels.ts` `axisLabels()` | `time_display` 兜底链挂在**轴刻度文案**上；刻度 0 ⇒ 函数不被调用 |
| ③ 未知区仅 60px 且无翻页 | `.../TimelineBand.tsx` + `timeline-band.ts`（`BAND_UNK_MAX=60`） | 列表高 48px ≈ 2 行 |

### 数据面根因：`time_display` 无法成为 `time_value`

- 提取提示词**已**要求 LLM 输出 `time_value`（累计天数，无法换算则 null）—— 实测非空率 **0%**（提示词产不出数值）。
- **`inkflow timeline normalize` 不能补这个洞**：其链路 `plan_reanchor` → `normalized_days` → `to_days`（`domain/services/_timeline_timebase.py`）**只对已有数值做段内重锚**（项目时基归一），**不做「文本 → 数值」解析**。
- 真实 `time_display` 语料（157 条，110 个不同值）**绝大多数是叙述式相对/模糊表达**：`过了两天` / `那年冬天` / `卯时三刻` / `三十二岁` / `初五` / `有一天` / `当年`。确定性解析器实测只能覆盖 **≈ 10–17%**；其余 **~78% 原文本身无绝对时间量**。

## 决策

### ① 不变量：正式表零未定事件（**写路径准入**）

提取管线**不得**把 `time_value is None` 的事件写入 `timeline_events`。判定时点 = 该事件**后置归一之后**。

> 语义依据（用户 2026-10-11 原话）：「不允许有未知。未知应该是作品中或读者未知，但**作者是必须已知的**。所有自动提取时未知的，统一**不能直接放到时间轴**，而是需要在一个**暂存区由作者确认**。」

### ② 后置时间归一：确定性文本解析器（**零 LLM**）

新建 `domain/services/_timeline_text_time.py`（纯函数）：`time_display` 原文 → `value` + `unit`（+ `era`），**逐条独立、不猜、不推算、不做跨事件锚定**。覆盖形态：纪年式 / 真序数 / 数量 / 月日（含中文数字）。**不覆盖**相对与模糊表达（→ 待确认区 + reason）。

- **不引入第二遍 LLM**：① 提示词已要求且实测产不出（0%）；② 用户语义是「不确定 → 交作者确认」，解析失败进暂存即天然满足；③ 确定性可测、零 token；④ 与 0.18.0 的「agent 定时自动补全」（#1583）职责不重叠。
- **单位口径**：保留原单位（`time_unit` 即尺度标签，f12 §2.7 S1/S3 不变）；§2.7 S2 常量表仍承担比较前归一。

### ③ 未定入暂存（两段式同构）

解析失败者连同 `reason` 落 `extract_staging`（`entity_type=timeline_event`），**确认前正式表零变更**（与 #1545/#1546 同构）。

### ④ 存量未定事件：不迁移、不丢弃

本版之前已落库的未定事件**不搬、不删** —— 在待确认区呈现为待处理项（确认 = 补时间后 `PATCH`；丢弃 = `DELETE`）。待确认区 = **暂存项 ∪ 正式表未定事件**。

### ⑤ 展示面：「未知」退役

世界序**不再渲染「未知」区块**（`BAND_UNK_MAX` 限高区退役），替换为**分页可达 100% 的待确认区**；确认**强制**带时间 ⇒ 上轴事件必有时间 ⇒「零未知」是**结构不变量**而非渲染 suppress。

## 备选方案

| 决策点 | 未选项 | 为什么不选 |
|---|---|---|
| 数据面 | A1-b **只强化提取提示词** | 已实测不足（`time_value` 0%）—— 提示词产不出数值 |
| 数据面 | A1-c **不补数据面** | 世界序永远 0 刻度，「按刻度分页」形同虚设 |
| 数据面 | **第二遍 LLM 把原文换算为数值** | 0.18.0（#1583）职责；本版引入会与「作者确认」语义重叠且不可测 |
| 归一 | **相对型按叙事序锚定**（`第二天` → 上一事件 +1 天） | 产出**推算值**（看起来对但可能错），与「作者必须已知」相悖（`degraded ≠ 通过`）。若要做 → 归 #1583 |
| 存量 | **一次性迁移**把正式表未定事件搬进暂存 | 破坏性写、需显式工具；前端合并两条来源**零迁移、零丢失**即达成同一效果 |
| 展示面 | A2-b **并入未知区 + 仅把未知区改可翻页** | 仍看不到时间原文 = 本次缺陷的表象 |
| 展示面 | A2-c **用 `narrative_position` 当刻度伪定位** | **语义错误**（该字段是线性序号，非时间），与 #1323/#1374 既有拍板冲突 |
| 浏览方式 | A3-b **提高限高 + 显式滚动条** | 222 条仍难用；且违背「画布高度不随未知数增长」（#1564 拍板） |

## 影响

**变得更容易**
- 世界序「零未知」成为**结构不变量**（不靠渲染层 suppress），与「按刻度分页 / 时间主轴」（#1564）恢复可用。
- 未定事件**不丢、原文可读、可逐条定夺** —— 待确认区是真源，不是兜底。
- 「后置归一」是确定性纯函数：可测、零 token、可复用（将来 CLI 批量补跑）。

**变得更难 / 需要接受**
- **提取产物的可见性被数据面裁切**：解析失败者**不在** `timeline_events`（机器可读面），只在暂存 / 待确认区。搜索、审计、MCP `manage_timeline` 等消费 `timeline_events` 的路径**看不到**这些未定事件 —— 这是刻意的（作者未确认前它们不是「正式事件」）。
- **存量数据与不变量不一致**（本版前已落库的未定事件仍在正式表）—— 以 ④ 承接，**不做回溯迁移**。
- **确定性解析器的覆盖率是硬上限**（实测 ~10%）—— 剩余靠作者（本版）或 #1583（agent 定时补全，0.18.0）。
