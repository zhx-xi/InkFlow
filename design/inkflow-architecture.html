架构风格

  • • 模块化单体（ADR-001），非微服务
  • • 领域层零框架依赖（CI 强制，ADR-015）
  • • Protocol 端口隔离，为按需拆分预留
  • • 本地优先：SQLite + 免认证（Phase 1-3）

多表现层共享领域

  • • REST API = 本地内核通信契约（ADR-021）
  • • CLI / MCP 是同等地位的表现层适配器
  • • GUI（Electron）渲染层复用 React 云 Web
  • • SSE 一条代码路径两用（F23，ADR-021）

数据流

  • • GUI/CLI → API → 领域服务 → Port
  • • LLM：ChatOpenAI 路由（custom base_url 兼容多 Provider）
  • • 编排：LangGraph StateGraph 角色链
  • • 检索：Chroma + BGE（F14，ADR-013）
