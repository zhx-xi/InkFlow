云端拓扑（ADR-024）

  • • 同 FastAPI 双前缀：/api/v1 + /admin
  • • 共享 domain/infrastructure，差异仅在认证与路由
  • • 管理面与用户面认证完全隔离（不同 issuer/audience）
  • • 拆分后路：api/user/* 与 api/admin/* 独立包 + 独立 DI

安全边界

  • • owner_id + Repository 强制过滤（防水平越权）
  • • LLM API Key 云端零存储（BYOK 客户端直连）
  • • skill 可执行体拒收（仅 Prompt 白名单上云）
  • • 云端 1.0 Gate：越权矩阵 + RBAC + 审计 + MFA

部署与本地兼容

  • • nginx + API + 前端静态 + PostgreSQL(pgvector) + MinIO
  • • 不做微服务/K8s（与 ADR-001 一致）
  • • 本地路径零改动（SQLite/Chroma/免认证保持）
  • • 前端一套代码两用：云 Web + GUI 内嵌
