#1350 · 位置徽标 位置徽标文案规则：first_chapter_id 非空且能在章节序中定位 → 「第 N 章 · <location>」（N = 章序位 + 1；location 为空时只显「第 N 章」）；为空 / 映射缺失 → 回落 location 原文（不伪造章号）；最终文本为空则不渲染徽标。存量数据 零回填（不解析 location 自由文本）。本图各行徽标即该形态（示例 location 本身已含章号，故视觉不变、PNG 无需重截）。
