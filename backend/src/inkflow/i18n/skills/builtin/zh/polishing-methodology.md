# 润色方法论

## 目标

本 skill 用于在内容不变的前提下润色章节文笔：精炼句式、优化节奏、统一用词，
提升阅读体验。适用于正文内容已定稿、需要文笔层面收尾打磨的场景。

## 方法步骤

1. **取前文基线**：获取前文摘要，确认既有文风、称谓、称谓变体、常用句式，
   润色后必须与之连续，不得自成一套腔调。
2. **逐段精炼句式**：合并冗余修饰、拆分过长句、消除重复用词，
   保持信息量不变（同一句只改说法，不删事实）。
3. **调节奏**：按场景性质控制句子长短与段落密度——
   紧张段落用短句、舒缓段落用长句，避免全章同一节奏。
4. **统一用词与指代**：同一对象全章同一称呼，同一动作全章同一动词，
   清除同义混用（尤其角色指代与专有名词）。
5. **查细节瑕疵**：删重复修饰、修语病与标点、确认语气与人设和场景氛围相符。
   顺手核一遍时间表述是否相对化（避免绝对年份混入）。
6. **收尾统计**：统计字数、向用户说明改动幅度。

## 边界

- 不改变情节与人物行动：影响剧情走向、事件结果或角色决策的改动属于修订而非润色。
- 不改设定表述：角色能力、称谓、世界观术语的字面是设定锚点，
  发现它们有问题要报告，不擅自「润」成别的说法。
- 不做结构级调整：场景顺序、段落重组与增删内容不在本 skill 范围内。
- 保持作者风格：只清除明显冗余与瑕疵，不把文本改写成统一模板腔。

## 示例

润色「第 12 章」：取前文摘要确认作者惯用短句与第三人称限知；
逐段合并冗余修饰、统一主角指代、把对峙段拆为短句提升节奏；
核对时间表述统一为「三日后」这类相对口径；完成后统计字数并回复改动摘要，
正文内容、情节与设定表述保持不变。

## 交付前自检

润色稿交付前逐条确认：

- [ ] 信息未减：没有任何事实、动作、对白被删（只改说法）
- [ ] 情节未动：事件结果、角色决策、场景顺序与原文一致
- [ ] 设定表述未改：称谓、能力名、世界观术语保持原样
- [ ] 文风连续：与前文的句式习惯、称谓变体一致，未自成腔调
- [ ] 节奏有变化：紧张段短句、舒缓段长句，全章非同一节奏
- [ ] 用词已统一：同一对象同一称呼，同一动作同一动词
- [ ] 字数已统计：向用户报告改动幅度

## 与修订的边界判定

遇到不确定的改动，用一张判据表决定归谁：

| 改动内容 | 归属 | 理由 |
|----------|------|------|
| 同一句话说法的变化 | 润色（本 skill） | 信息不变 |
| 事件结果或角色决策变化 | 修订 | 影响剧情走向 |
| 增删段落内容 | 修订 | 属结构级调整 |
| 称谓 / 能力名 / 术语字面 | 都不是 → 报告用户 | 设定锚点，需设定流程 |

润色最容易越界的方式是「顺手改掉读起来别扭的设定表述」——
那些字面往往正是设定与一致性检查的锚点，改了就切断了引用链。
因此本 skill 对设定表述一律只报告、不修改。

## 常见文笔病症与处方

| 病症 | 表现 | 处方 |
|------|------|------|
| 修饰堆叠 | 一句多个形容词叠加 | 保留最具体的一个，删其余 |
| 长句缠绕 | 一句含多个转折与从句 | 按语义切分为两到三句 |
| 同义混用 | 同一对象多种称呼交替 | 全章统一，必要时保留有意的变体 |
| 节奏平板 | 全章句长接近、段落等长 | 紧张段压短、舒缓段放长 |
| 空洞抒情 | 用形容词代替具体感受 | 换成可感的动作、细节或物件 |
| 解释过度 | 叙述把意图与成因说尽 | 删解释，留动作与反应 |
| 口语残留 | 出现现代口语与网络用语 | 按世界观时代口径替换 |

「解释过度」与「口语残留」是最伤长篇沉浸感的两类，
润色时应优先巡视章末与情绪高点段落——这两处最易出现。

## 润色时的设定红线

润色只处理文字层，不承担一致性职责，但改写过程本身会踩到一致性问题。
遇到下列情况一律停下报告，不做「顺手修好」：

- 角色称呼在章内不统一 → 属设定漂移，报告交审校 / 世界观顾问，
  润色不得自行选定一个「更好听」的称呼
- 时间表述前后矛盾（「次日」与「三日后」并存）→ 属时间线问题，
  只统一为原文中证据更充分的一方并标注，不发明第三个时间口径
- 某条伏笔的线索文字被改得读不出来 → 伏笔锚点被削弱，
  保持线索物名称与可识别特征原样

一句话原则：润色可以让文字更好读，但不能让任何设定锚点变得不可追溯。
宁可留下读起来稍别扭的表述，也不要切断引用链。
