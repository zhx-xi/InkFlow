# 世界观方法论

## 目标

本 skill 用于校验角色档案与伏笔是否符合项目世界观设定，发现矛盾时给出修正
建议而非直接改写。适用于设定档案更新、新章节引入新设定或需要全局一致性
把关的场景。

## 方法步骤

1. **先读世界观基准**：读出力量体系、地理、时代、社会规则、禁忌等
   不可违背的约束，整理成一份基准清单。基准未读到就不要下判断。
2. **校角色档案**：逐项检查角色的出身、能力、关系、所属势力是否与基准冲突；
   特别注意「能力来源」这类跨条目依赖（能力依赖某资源 → 该资源在世界观中的状态）。
3. **校伏笔走向**：伏笔内容与计划兑现方式是否越过世界观边界；
   若伏笔要求一个世界观不允许的结果，标记为设定级矛盾而非情节问题。
4. **查设定漂移**：把新档案/新章节用到的设定点与既有条目逐条对照，
   找出同名不同义、同义不同名、规则前后放宽三类漂移。
5. **校时间口径**：设定中的时代、纪年、事件先后是否与项目时间轴自洽。
6. **输出建议清单**：逐条列矛盾点、世界观依据（引用条目原文）、建议方案。

## 边界

- 只建议不改写：本 skill 产出建议清单，实际修改由用户或修订方法论执行。
- 不扩大解释设定：世界观未明示的细节不作硬性推断，标注为待确认项。
- 与审计的职责边界：本 skill 聚焦世界观规则本身，章节内部叙事一致性问题交给审计。
- 不硬堵创作空间：设定冲突有两种解法（改设定 / 改角色），
  本 skill 只负责指出冲突并给出两条路，选哪条由用户拍板。

## 示例

校验新角色「矿脉巫师」：读世界观基准得知力量依赖地脉水晶、且设定中水晶
早已枯竭。校档案发现该角色能力直接依赖水晶，且前文未埋再生伏笔 → 判定
设定级矛盾。输出两条建议：① 调整能力来源为残留晶屑，② 补充枯竭例外条款
并在前文补埋伏笔；标注建议 ① 改动面更小，交用户决定。

## 交付前自检

建议清单交付前逐条确认：

- [ ] 基准已读：所有判断都基于读到的世界观条目，未凭印象推断
- [ ] 依据可查：每条建议引用了世界观条目原文，而非概括性说法
- [ ] 三类漂移已查：同名不同义、同义不同名、规则前后放宽
- [ ] 跨条目依赖已查：角色的能力来源、资源状态、势力归属均已核对
- [ ] 伏笔越界已查：伏笔的兑现方式未要求世界观不允许的结果
- [ ] 时间口径已查：设定中的时代、纪年与项目时间轴自洽
- [ ] 给了两条路：每条冲突都提供「改设定」与「改角色/情节」两种解法

## 三类设定漂移的识别口径

| 类型 | 表现 | 判定要点 |
|------|------|----------|
| 同名不同义 | 同一术语在两处含义不同 | 比对术语的定义句，而非只看名称 |
| 同义不同名 | 同一事物被换了说法 | 比对功能描述，而非只看名称 |
| 规则放宽 | 后文允许了前文禁止的事 | 找「例外条款」是否被追溯补充 |

前两类是命名问题（改动小），第三类是规则问题（改动大且影响面广）——
本 skill 应在建议中明确标注属于哪一类，便于用户判断改动成本。

## 与审计的分工

两个 skill 都查一致性，但对象与结论不同：

| 对比项 | audit-methodology | worldview-methodology（本 skill） |
|--------|-------------------|-----------------------------------|
| 对象 | 章节正文 vs 既有记录 | 设定档案 vs 世界观基准 |
| 触发 | 草稿完成后 | 档案更新 / 新设定引入 / 全局把关 |
| 产物 | findings 清单（含分级） | 冲突清单 + 双解法建议 |
| 决策权 | 无（只报告） | 无（给两条路，用户拍板） |

边界判定：矛盾出在「章内叙述」→ 交审计；
矛盾出在「设定条目本身之间」→ 本 skill 负责。
两者都涉及同一条目时，应分别成条，不复用同一条 finding。
