# 审校方法论

## 目标

本 skill 用于对章节草稿执行一致性审计，检查字数、设定漂移与伏笔状态等
方面的矛盾或遗漏，输出结构化 findings。适用于正文初稿完成、需要质量把关
的场景。

## 方法步骤

1. **统计体量**：先统计章节字数，确认是否符合目标篇幅，偏差过大时记为一条发现。
2. **建证据链**：获取前文摘要与本章涉及的事件序列，把正文事实按发生顺序排列，
   再与项目时间轴对照，找出顺序错位、跨度矛盾、同刻两地的时序问题。
3. **查设定漂移**：逐条比对本章的角色档案与世界观设定——称呼、能力上限、
   关系进展、世界观禁忌。凡正文出现档案里没有的能力/称谓/规则，即为漂移候选，
   必须引用档案原文作为证据，不得凭印象判定。
4. **核伏笔账**：对照伏笔清单检查本章应埋、应回收两项；漏埋与漏收分别成条，
   并标注原计划章节号。
5. **定级归类**：把每条发现按影响分级——阻断级（角色/设定硬冲突、时间线穿帮、
   数据链断裂）、建议级（节奏、冗余）、存疑级（证据不足）。
6. **输出结构化 findings**：逐条标注问题类型、位置、证据原文、影响级别与修改建议。

## 边界

- 只审计不改写：本 skill 产出问题清单，正文修改由修订方法论或写手完成。
- 不臆断作者意图：证据不足的疑点标注为「存疑」而非直接判定错误；
  尤其注意不得把作者的页面设定、后记、说明性文字当作正文缺陷。
- 避免噪音式报错：重复问题合并为一条，聚焦影响读者理解的一致性缺陷。
- 不越权下结论：审计只管「是否与既有设定冲突」，
  「设定本身该不该改」由世界观顾问与用户裁决。

## 示例

审计「第 12 章」：字数超目标 2000 字（建议级）；时间线比对发现第 10 章记为
「三日后」而本章称「次日」（阻断级，需回查上游）；设定比对发现主角称呼与前文
不一致、且动用了档案未记载的能力（阻断级，设定漂移）；伏笔账发现第 3 章信物
应本章回收却缺失（阻断级）。共 4 条 findings，每条含类型、位置、证据与建议。

## 交付前自检

findings 交付前逐条确认：

- [ ] 每条都有证据：引用原文片段与档案条目，不用「感觉不对」当依据
- [ ] 每条都有位置：具体到段落或情节，可被定位复核
- [ ] 每条都有分级：阻断级 / 建议级 / 存疑级，不混为一谈
- [ ] 无重复条目：同一问题在不同位置不重复报
- [ ] 未把作者侧文字当缺陷：后记 / 说明 / 待办标记不计入正文问题
- [ ] 未越权判定设定：只报「与档案冲突」，不裁定「档案该改」
- [ ] 覆盖四项：体量、时间线、设定漂移、伏笔账均已检查

## 分级口径

| 级别 | 判据 | 处理建议 |
|------|------|----------|
| 阻断级 | 角色/设定硬冲突、时间线穿帮、应收未收伏笔 | 必须处理后才可进入修订 |
| 建议级 | 节奏拖沓、冗余重复、篇幅偏差 | 交用户决定是否本轮处理 |
| 存疑级 | 证据不足或依赖作者意图 | 只提示，不要求修改 |

分级是本 skill 的核心产出：把「一堆问题」变成「可排期的问题」，
下游修订师据此决定改哪些、先改哪些。

## 审计口径

| 维度 | 查什么 | 证据来自 |
|------|--------|----------|
| 体量 | 字数是否达目标、章节间是否失衡 | 章节统计 + 目标篇幅 |
| 时间线 | 事件顺序、时间跨度、同刻两地 | 前文摘要 + 项目时间轴 |
| 设定漂移 | 称呼、能力上限、关系进展、世界观禁忌 | 角色档案 + 世界观条目 |
| 伏笔账 | 应埋未埋、应收未收 | 伏笔清单 + 计划章节号 |
| 叙事一致 | 视角跳变、人称混用、场景跳切 | 正文自身 |

审计只做「与既有记录比对」，不做审美判断：
「这段写得不好看」不是 finding，「这段与第 3 章档案冲突」才是。
审美与节奏感受交用户判断，本 skill 不越位。
